# 받아가게 매달 정보 업데이트 규칙 (예약 작업용)

매달 1일 오전에 예약 작업이 이 규칙대로 `data/content.json` 하나만 고쳐서 main에 바로 올린다.
앱은 켜질 때 GitHub의 이 파일을 받아가서 바로 반영한다 (앱 업데이트·구글 검토 없음).
**틀린 정보는 사장님들께 실제 피해가 된다. 확인되지 않은 것은 넣지 않는다. 애매하면 바꾸지 않는다.**

## 1. 고칠 수 있는 것 / 없는 것
- 고치는 파일은 **`data/content.json` 하나뿐**. 앱 코드(src/), 그림, 설정, 다른 파일은 절대 건드리지 않는다.
- 파일 구조(칸 이름, schema 값)를 바꾸지 않는다. 새 칸을 만들지 않는다 (아래 표에 있는 칸만).
- `programs[0]`(경영안정바우처, `detailed: true`)는 구조가 달라서 **마감일·금액 문구만** 고칠 수 있다.

## 2. 공식 출처만
- 지원금: 소상공인24(sbiz24.kr), 소상공인시장진흥공단(semas.or.kr, ols.semas.or.kr), 기업마당(bizinfo.go.kr), 중소벤처기업부(mss.go.kr), 각 시·도청·신용보증재단(*.go.kr, *.or.kr) 공고문.
- 뉴스: 중소벤처기업부 보도자료(mss.go.kr List.do?cbIdx=86), 대한민국 정책브리핑(korea.kr), 각 부처 보도자료.
- 금리: 한국은행(bok.or.kr) 통화정책방향 결정 발표, 연간 회의 일정.
- 최저임금: 고용노동부 고시.
- 블로그·카페·언론 요약 기사·광고성 사이트는 출처로 쓰지 않는다 (사실 확인용으로만 보고, 반드시 공식 공고로 다시 확인).

## 3. 매달 할 일 (순서대로)
1. `git pull` 후 `node scripts/content-check.mjs` 로 지금 상태가 통과하는지 먼저 확인.
2. **지원금(programs)**
   - 기존 항목: 공식 공고에서 마감일·금액·대상·접수 방식이 바뀌었는지 확인하고 고친다.
   - 마감이 지난 항목: 그대로 두면 앱이 '접수마감'으로 보여 준다(매년 재공고 안내). 같은 사업의 새해 공고가 나오면 **같은 id**로 내용·마감일을 바꾼다.
   - 폐지가 확인된 사업만 삭제한다. 한 번에 3개 이하.
   - 새 사업: 소상공인 대상이고 공고문으로 대상·금액·마감일이 모두 확인될 때만 추가. id는 지금 가장 큰 숫자 id + 1 (숫자 id는 재사용 금지).
   - `applyUrl`: 그 사업의 **공식 신청·공고 페이지** 주소(https, 공식 기관 도메인). 확실하지 않으면 넣지 않는다(없으면 앱이 소상공인24로 연결).
3. **뉴스(news)**: 지난달 소상공인 관련 정부 발표 중 사장님께 실제로 도움 되는 것 2~4건 추가. 오래된 것(6개월 넘은 것)부터 빼서 전체 10~14건 유지. `newsUpdated`를 오늘 날짜로.
4. **금리(bok)**: 지난달 금통위 결정이 있었으면 `rate`(금리·발표일·변동폭)와 `history`(맨 뒤에 추가, 4개 유지) 갱신. 다음 해 회의 일정이 발표됐으면 `meetings`에 추가(지난 날짜는 남겨도 됨, 순서대로).
5. **최저임금(minWages)**: 다음 해 금액이 고시됐으면 한 줄 추가 (보통 8월 고시).
6. `updated`를 오늘 날짜(YYYY-MM-DD)로.
7. `node scripts/content-check.mjs` → **✅ 통과일 때만** 커밋·푸시. 실패하면 고쳐서 다시, 고칠 수 없으면 그 부분은 되돌린다(이번 달은 바꾸지 않음).
8. 커밋 메시지: `정보 업데이트 YYYY-MM: 지원금 +n/-n/수정 n, 뉴스 +n, 금리 …` — 바뀐 항목과 출처 주소를 본문에 적는다.

## 4. 칸별 형식 (기존 항목과 같은 말투·길이)
### 지원금 (programs)
| 칸 | 형식 | 예 |
|---|---|---|
| id | 숫자(바우처만 "voucher") | 27 |
| name | 공식 사업명 (80자 이내) | "경기도 소상공인 정책자금" |
| region | 전국·서울·부산·대구·인천·광주·대전·울산·세종·경기·강원·충북·충남·전북·전남·경북·경남·제주 | "경기" |
| regions | (여러 시·도일 때만) 위 지역 배열 | ["대구","경북"] |
| category | 고정비·에너지·임차료·경영·디지털전환·창업·보증·고용·신용·재기 | "경영" |
| target | 지원 대상, 공고문 기준 한 문장 | "경기도 소재 사업자등록을 마친 소상공인" |
| amountLabel | 금액 요약 (80자) | "최대 5,000만원 (연 2.5%)" |
| deadline | YYYY-MM-DD, 상시는 2099-12-31 | "2026-12-31" |
| recurring | 상시·예산 소진 시 마감이면 true | true |
| recurringNote | (recurring이면 필수) 접수 방식 | "경기신용보증재단 통해 연중 상시 접수, 예산 소진 시 조기 마감" |
| verified | 항상 true (확인 안 된 항목은 넣지 않음) | true |
| note | 사장님께 쉬운 말로 1~2문장, "~해요" 말투 | "일반 정책자금보다 낮은 금리로 … 공고를 확인하세요." |
| applyUrl | (선택) 공식 신청·공고 페이지 https | |
| popularity | 숫자(정렬 참고용, 새 항목은 300) | 300 |

### 뉴스 (news)
| 칸 | 형식 |
|---|---|
| id | "m" + 다음 번호 (예 "m12"), 중복 금지 |
| title | 80자 이내, 핵심을 한 줄로 (기존처럼 "— " 뒤에 요점) |
| source | 발표 기관 (예 "중소벤처기업부") |
| date | YYYY.MM.DD (발표일) |
| category | 정책자금·고정비·인건비·지역·상권·세제·제도·디지털 |
| readTime | "2분" 같은 형식 |
| summary | 1~2문장, "~해요" 말투 |
| bullets | 요점 3~4개 |
| url | 공식 원문 https |
| image / imageSource | (선택) 정책브리핑 대표 사진 주소와 출처. 사진을 쓰면 imageSource 필수. 연합뉴스 등 언론사 사진은 쓰지 않는다 |
| programId | (선택) 앱 안 관련 지원금 id — 실제로 있는 id만 |

## 5. 절대 하지 말 것
- 검사 실패 상태로 올리기, `--no-links`로 링크 검사 건너뛰고 올리기
- 추측한 금액·날짜 넣기, 작년 공고를 올해 것처럼 쓰기
- 다른 파일 고치기, 앱 빌드·Play 업로드 (이 작업은 정보 파일만)
- 개인정보·광고·홍보 문구 넣기
